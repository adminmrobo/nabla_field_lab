# 같은 ∇, 다른 현장 — 로봇 팔과 옵션 가격으로 배우는 좌표 바꾸기

연구실 해설 · ∇ 특별편(좌표 바꿔 보기)의 응용 독립편
글 · 안상선 ((주)M-Robo 대표)

공개 주소: https://adminmrobo.github.io/nabla_field_lab/

## 구성
| 방 | 제목 | 실험 |
|---|---|---|
| 0 입구 | 한 칸의 실제 길이(축척 인자) | 부채꼴 슬라이더 |
| 1 공장동 | 팔이 닿는 곳(원통좌표) | 3D 로봇 팔·도넛 작업 공간 |
| 2 공장동 | 쭉 편 팔의 함정(야코비안) | 한 칸 상자 |
| 3 공장동 | 드론 길 찾기(그래디언트·라플라시안) | 단순 지도 vs 주변 평균 지도 |
| 4 거래소동 | 옵션 가격 언덕(그리스 문자 = ∇ 성분) | 3D 가격 곡면 |
| 5 거래소동 | 로그 좌표로 바꾸면 | 가격 경로 부채꼴, 눈금 전환 |
| 6 거래소동 | 두 자산을 돌려 보기(회전 좌표) | 점구름과 축 돌리기 |
| 대결 | 박사 vs 조수 좌표 고르기 5판 | 독자가 심판 |

- 원자료: matharium 「Vector Derivatives — Same operators, different coordinates」 (원통좌표 기호 s → ρ)
- 캐릭터: 연구실 식구(fruitfly-lab-expressions)
- 로봇 치수·옵션 수치·수익률은 모두 교육용 예시이며, 경영·투자 권고가 아닙니다.
